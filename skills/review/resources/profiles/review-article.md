# Profile: journal review article

## Goal
A narrative review article suitable for submission to a peer-reviewed journal. Same evidence standards as the seminar profile, tighter prose, no cover page.

## Structure
1. Abstract / תקציר — 200–250 words, structured as Background, Methods, Results, Conclusions.
2. Introduction / מבוא — problem, why a review is needed now, aims.
3. Methods / שיטה — search strategy, inclusion criteria, screening, synthesis approach (from `project.yaml` → `review_method`).
4. Thematic sections (3–5), each organized around a theme from the theme matrix.
5. Discussion / דיון — principal findings, comparison with the field as reflected in the sources, strengths and limitations of the review.
6. Conclusions and future directions / מסקנות וכיווני מחקר.

## Length budget
Introduction 12%, Methods 8%, Thematic sections 55%, Discussion 18%, Conclusions 7%.

## Register
Same as the seminar profile. Prefer summary tables that compare studies on design, sample, measures and main result.

## Formatting
- No cover page (the build script prints the title, author and date at the top of page 1 instead)
- Font and spacing as in the seminar profile
- Bibliography in APA 7 (the build script currently formats APA 7 only)
- `cover: false` is set automatically for this profile
